# xls2spread

把「固定資產建設改良擴充計畫及成本效益分析表」這類 Excel 轉成**天地線固定的對開表**，
手動調列高／行距，再 Cmd+P 存 PDF。

## 兩種用法

**`index.html`（主要）** — 單一檔案，開起來把 .xlsx 拖進去就開始調。
不需要安裝任何東西、不需要後端，檔案不會離開你的電腦。
解 zip 用瀏覽器內建的 `DecompressionStream`、讀 XML 用 `DOMParser`，沒有任何外部函式庫。

**`xls2spread.py`（只有 .xls 才需要）** — 瀏覽器讀不了舊版 .xls，用這支轉：

```bash
python3 xls2spread.py 固資成本效益分析表.xls
```

產生同名 .html（會用 LibreOffice 先轉檔，需要 `soffice`）。
也可以直接在 Excel 另存為 .xlsx 再丟給 index.html，就用不到這支。

兩邊產出的版面模型是同一套，實測 3226 格、CSS 規則全部一致。

## 放到網路上

都是純靜態，push 上去就能用：

| 平台 | 做法 |
|---|---|
| GitHub Pages | 推 repo → Settings → Pages → 選 branch。`index.html` 在根目錄就直接是首頁 |
| Hugging Face Space | 建 Space 選 **Static**，把 `index.html` 放根目錄即可（Static Space 的進入點一定要叫 index.html） |

因為解析全在瀏覽器端做，**公開放著也不會讓別人拿到你上傳的預算檔**。
瀏覽器需求：Chrome 80+／Safari 16.4+／Firefox 113+（`DecompressionStream`）。

`.gitignore` 已經擋掉 `*.xls`／`*.xlsx`，避免測試用的實際預算檔被推上去。

## 版面怎麼決定的

全部從 Excel 讀出來，不是寫死的：

| 版面元素 | 來源 |
|---|---|
| 左頁／右頁欄位 | 欄分頁線（本檔在 F/G 之間） |
| 每頁列數 | 原檔的水平分頁線 |
| 重複表頭 | 列印標題列（第 1-6 列） |
| 紙張、邊界 | 版面設定 |
| 列高、欄寬、字型、對齊、縮排、框線、數值格式 | 儲存格樣式 |
| 合計＋附註 | 下框線是粗線的那列以後，釘在天地線位置 |

和原檔不同的地方，都是為了做到要的效果：

- **天地線固定**：每頁表格高度鎖成同一個值，不足的用一列空白撐開，直線一路拉到地線。
  Excel／LibreOffice 是讓地線跟著最後一列跑，所以每頁高度都不一樣。
- **列線去掉**：資料列只留直的欄線，橫線只出現在表頭和天地線。
- **第一組對開的表名不加（續）**：原檔標題列每頁重複，（續）會印在每個偶數頁；
  只有第 2 頁該是「⋯綜計表」，第 4 頁以後才是「⋯綜計表（續）」。
- **依列高自動分頁**（預設開）：列高調大塞不下就把尾端的列推到下一組，調小就把後面的列往前補，
  地線都不動。關掉的話地線會跟著內容撐下去、超出紙張的列列印時會不見。

  **原檔的手動分頁是硬邊界，資料不會跨過去往前流**（它們是一個基金一頁的語意分頁，不是照高度切的）。
  要讓某處往前流，點該頁左上角的「⛔ 手動分頁」標記把它拿掉；
  或按「清掉全部手動分頁」變成完全照列高流動（本檔列高縮 30% 時：18 組 → 11 組）。

## 預設用 HTML 的方式排，不照抄 Excel

Excel 的列高是被儲存格網格逼出來的（同一列左右兩邊要一起遷就最高的那個），
分頁也是遷就格線切的。HTML 沒這個限制，所以**第一次載入就會照內容重排**：

- 每一列壓到左右頁文字實際需要的高度（本檔總列高 10890pt → 7594pt，少 30%）
- 分頁完全由高度決定，不沿用原檔的分頁點（本檔 18 組 → 11 組，每頁填到 90~99%）

要 Excel 原樣按「重設」，要再排一次按「HTML 重排」。

`縮放` 的預設值是照 Excel 的 fitToPage 算法回推的（把較寬的那半頁縮到版心寬度）。
欄寬在檔案裡存的是「幾個字元」，換算成實際尺寸要乘預設字型的數字寬度，
這個基準經過轉檔會失真，所以推出來的值有幾個 % 的誤差
（本檔推得 80.7%，量 LibreOffice 實際輸出是 77.0%）。
在意就把「縮放」拉到你要的值，會自動存起來。

## 操作

| 動作 | 做法 |
|---|---|
| 單獨調某列列高 | 拖該列下緣／點選後 ↑↓（Shift ×5）／直接填「本列高」 |
| 該列自動配高 | 雙擊該列 |
| 決定停在某一列 | 點左側標尺的累積高度數字 |
| 拿掉擋住流動的分頁 | 點該頁左上角的「⛔ 手動分頁」 |
| 完全照列高重排 | 「清掉全部手動分頁」 |
| 全域 | 縮放、行距、字級、天地線高、末頁地線（合計那一組另設） |
| 存檔 | 自動存在瀏覽器；「匯出設定」可存成 json 帶著走 |

左右頁同一列一定同高（同一個列高值套到兩邊），所以奇偶頁永遠對齊。

**累積高度**（紙上 mm，表頭已扣掉）：每頁右上角 `累積 195.1 / 219.2mm ・剩 24.1mm`；
左側標尺逐列標出累積值，最後一列標 `▏滿`。紅色底線代表那格文字被切掉，該列要加高。

列印用 A4 直式、邊界設「無」、關掉頁首頁尾、縮放 100%（版面已是實際尺寸）。
實測 Chrome 列印為 36 頁、209.9×297mm、無空白頁。
