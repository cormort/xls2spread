# xls2spread

把「固定資產建設改良擴充計畫及成本效益分析表」這類 Excel 轉成**天地線固定的對開表**，
逐列調好列高後直接列印成 PDF，或寫回 xlsx 回 Excel 微調。

## 要解決什麼

政府預算的固資成本效益分析表是一張**跨頁對開表**：奇數頁放基金及計畫名稱與資金來源，
偶數頁放計畫內容與預算數，兩頁的同一列必須對齊，而且每一頁的天地線
（表格上下那兩條框線）要落在同一個位置，整份翻起來才不會上下跳動。

用 Excel 排這種表會卡在四件事：

1. **列高被儲存格網格綁死** — 同一列左右兩邊得一起遷就比較高的那一邊，
   短的那邊就空在那裡。實測這份檔案有 30% 的列高是這樣來的純空白。
2. **地線跟著最後一列跑** — Excel 的表格框線畫到內容為止，每頁結束的位置都不一樣。
3. **牽一髮動全身** — 調一列列高，後面的分頁就跑掉，得反覆手動補分頁線。
4. **對齊只能用土法** — 為了讓文字換行後有縮排，得在儲存格裡插手動換行，
   再把補位的字設成白色。

## 怎麼解

**Excel 只當資料來源，版面交給 HTML/CSS。**

核心是一個分配問題：在**固定的天地線總高**裡分配所有資料列，
讓最終頁數最合理 —— 通常是最少，但不能為了省頁數犧牲資料的視覺呈現。
所以排版是每次重繪就整份重算的，不是一次性套版：

- 版面設定直接讀出來用：欄分頁決定左右頁怎麼切、列印標題列決定重複表頭、
  紙張邊界決定版心，儲存格樣式（字型、框線、對齊、縮排、數值格式）原樣重現，
  連白色文字的縮排土法都照樣還原。分散對齊（「全　　部」這種）是把每個字包起來用
  flex 推開，不靠 CSS 的 `text-align-last`，各家瀏覽器結果才一致。
- **天地線鎖死**：每頁表格高度固定，不足的部分用一列空白撐開，欄線一路拉到地線。
  末頁的合計與備註釘在底部，備註最底部對齊其他頁的地線。
- **列高不照抄 Excel**：載入就把每列壓到左右頁文字實際需要的高度，
  同一列左右頁共用同一個值，所以奇偶頁永遠對齊。
- **分頁自己算**：列高調大塞不下就把尾端的列推到下一組，調小就把後面的列補上來，
  地線都不動。要卡在特定位置再自己下分頁點。
- **Excel 裡看不見的列直接不輸出**：帶 hidden 旗標的列，以及列高被壓到比字級還小的列
  （本檔有 18 列、4.5~4.9pt，裡面留著沒清乾淨的舊值）。這種列在 Excel 看不到，
  照抄過來又被配高撐開的話，就會冒出不該出現的內容。本檔 209 列 → 191 列。
- **頁尾守則不強求**：群組標題（自己沒有計畫內容、下一列更縮排）或空白間隔列落在頁尾，
  會讓內容看起來斷掉。工具會試著把它推到下一頁，但**只在不會多印一頁的時候才這麼做**；
  真的會多一頁就維持原樣，改用橘色底線標出來讓你自己決定
  （本檔實測：3 處落單標題，套用守則後 0 處，組數維持 11 組不變）。
- 調完 Cmd+P 就是成品；或匯出 xlsx 帶著新的列高與分頁回 Excel。

## 兩種用法

**`index.html`（主要）** — 單一檔案，開起來把 .xlsx 拖進去就開始調。
不需要安裝任何東西、不需要後端，檔案不會離開你的電腦。
解 zip 用瀏覽器內建的 `DecompressionStream`、讀 XML 用 `DOMParser`，沒有任何外部函式庫。

**`xls2spread.py`（只有 .xls 才需要）** — 瀏覽器讀不了 BIFF 格式的舊版 .xls，
這支只做轉檔（用 LibreOffice，需要 `soffice`），排版一律回到 index.html：

```bash
python3 xls2spread.py 固資成本效益分析表.xls
```

手邊有 Excel 的話直接「另存新檔 → Excel 活頁簿 (.xlsx)」效果一樣，用不到這支。

都是純靜態，push 上去就能用：

| 平台 | 做法 |

因為解析全在瀏覽器端做，**公開放著也不會讓別人拿到你上傳的預算檔**。
瀏覽器需求：Chrome 80+／Safari 16.4+／Firefox 113+（`DecompressionStream`）。

`.gitignore` 已經擋掉 `*.xls`／`*.xlsx`，避免測試用的實際預算檔被推上去。

## 版面怎麼決定的

全部從 Excel 讀出來，不是寫死的：

| 版面元素 | 來源 |
|---|---|
| 左頁／右頁欄位 | 欄分頁線（本檔在 F/G 之間） |
| 每頁列數 | 原檔的水平分頁線 |
| 重複表頭 | 列印標題列（第 1-6 列） |
| 紙張、邊界 | 版面設定 |
| 列高、欄寬、字型、對齊、縮排、框線、數值格式 | 儲存格樣式 |
| 合計＋附註 | 下框線是粗線的那列以後，釘在天地線位置 |

和原檔不同的地方，都是為了做到要的效果：

- **天地線固定**：每頁表格高度鎖成同一個值，不足的用一列空白撐開，直線一路拉到地線。
  Excel／LibreOffice 是讓地線跟著最後一列跑，所以每頁高度都不一樣。
- **列線去掉**：資料列只留直的欄線，橫線只出現在表頭和天地線。
- **第一組對開的表名不加（續）**：原檔標題列每頁重複，（續）會印在每個偶數頁；
  只有第 2 頁該是「⋯綜計表」，第 4 頁以後才是「⋯綜計表（續）」。
- **依列高自動分頁**（預設開）：列高調大塞不下就把尾端的列推到下一組，調小就把後面的列往前補，
  地線都不動。關掉的話地線會跟著內容撐下去、超出紙張的列列印時會不見。

  **原檔的手動分頁是硬邊界，資料不會跨過去往前流**（它們是一個基金一頁的語意分頁，不是照高度切的）。
  要讓某處往前流，點該頁左上角的「⛔ 手動分頁」標記把它拿掉；
  或按「清除分頁」變成完全照列高流動（本檔列高縮 30% 時：18 組 → 11 組）。

## 預設用 HTML 的方式排，不照抄 Excel

Excel 的列高是被儲存格網格逼出來的（同一列左右兩邊要一起遷就最高的那個），
分頁也是遷就格線切的。HTML 沒這個限制，所以**第一次載入就會照內容重排**：

- 每一列壓到左右頁文字實際需要的高度（本檔總列高 10890pt → 7594pt，少 30%）
- 分頁完全由高度決定，不沿用原檔的分頁點（本檔 18 組 → 11 組，每頁填到 90~99%）

要 Excel 原樣按「重設」，要再排一次按「HTML 重排」。

`縮放` 的預設值是照 Excel 的 fitToPage 算法回推的（把較寬的那半頁縮到版心寬度）。
欄寬在檔案裡存的是「幾個字元」，換算成實際尺寸要乘預設字型的數字寬度，
這個基準經過轉檔會失真，所以推出來的值有幾個 % 的誤差
（本檔推得 80.7%，量 LibreOffice 實際輸出是 77.0%）。
在意就把「縮放」拉到你要的值，會自動存起來。

## 操作

| 動作 | 做法 |
|---|---|
| 單獨調某列列高 | 拖該列下緣／點選後 ↑↓（Shift ×5）／在「選取列」直接填列高數字 |
| 該列自動配高 | 雙擊該列 |
| 決定停在某一列 | 點左側標尺的累積高度數字 |
| 拿掉擋住流動的分頁 | 點該頁左上角的「⛔ 手動分頁」 |
| 完全照列高重排 | 「清除分頁」 |
| 一頁看起來上密下空 | 「本頁平均列高」把剩餘空白平均加到該頁每一列（「全部平均列高」一次做完全部） |
| 每列跟下一列拉開距離 | 「列間距」滑桿，全部頁面一起套用 |
| 全域 | 縮放、列間距、行距、字級、天地線高、末頁地線 |
| 回 Excel 微調 | 「匯出 xlsx」把列高與分頁寫回原檔 |
| 存檔 | 自動存在瀏覽器；「匯出設定」可存成 json 帶著走 |

左右頁同一列一定同高（同一個列高值套到兩邊），所以奇偶頁永遠對齊。

末頁的合計與備註釘在底部：勾「末頁對齊地線」時，**備註的最底部會落在其他頁地線的同一條線上**，
末頁的地線（合計下框線）自動被備註的總高度往上頂。取消勾選才手動指定末頁的總高。

**累積高度**（紙上 mm，表頭已扣掉）：每頁右上角 `累積 195.1 / 219.2mm ・剩 24.1mm`；
左側標尺逐列標出累積值，最後一列標 `▏滿`。紅色底線代表那格文字被切掉，該列要加高。

「列間距」和列高是分開存的：列高只記文字實際需要的高度，間距是排版時才加上去，
所以間距隨時可以拉，也不會被「全部平均列高」洗掉。

**匯出 xlsx**：把調好的列高（含列間距）與分頁寫回工作表，其餘位元組原封不動搬過去 ——
公式、樣式、欄寬、巨集、圖形都在，回 Excel 還能繼續微調。
注意 Excel 會用它自己的 fitToPage 縮放率列印（比工具的預設值小約 5%），
所以在 Excel 裡每頁會比預覽再鬆一點，分頁點不受影響。

列印用 A4 直式、邊界設「無」、關掉頁首頁尾、縮放 100%（版面已是實際尺寸）。
實測 Chrome 列印為 36 頁、209.9×297mm、無空白頁。

## 驗算與提示

- **驗算**（「檔案」群組）：用畫面上的數字重新核對階層加總
  （總計 = Σ主管 → 主管 = Σ基金（公司）→ 基金 = Σ大分類 → 大分類 = Σ各計畫）
  與交叉檢查（各「◯◯主管」加總、計畫別合計），不符的逐項列出；
  **原檔檢誤**讀 Excel 存檔時算好的「差異數」區，檢查是否全為 0。
  結果開在可捲動、可複製的面板（✗ 紅／✓ 綠，附「複製全文」）。
- **未設對齊的格**：原檔沒設對齊（Excel 的「通用」）時，靠左／靠右是依內容猜的，
  這些格子會標黃底提醒人工確認，列印、PDF 與匯出的 xlsx 都看得到；
  不想看到可在「檢視」群組取消勾選「黃底提示」。
- 工具列群組可收合（點群組標題），版面、檔案等較少動的群組預設收起，狀態會記住；
  最右側「輸出」群組固定放「列印/存 PDF」與「匯出 xlsx」。
